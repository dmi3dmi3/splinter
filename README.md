# Splinter

Self-hosted, local-first аналог Splitwise для компании друзей.
Android-приложение, опциональный сервер синхронизации на своём VPS.

- Полностью работает офлайн; сервер нужен только для синхронизации телефонов.
- Вся история — append-only журнал событий; балансы и план переводов — проекции журнала.
- Сервер не читает содержимое событий.
- Один скрипт установки на голый VPS, без домена и внешних сервисов.

Статус: проектирование. Читать [docs/proposal.md](docs/proposal.md).

## Структура

```
contract/   источник истины: схемы событий, спецификация расчётов, golden-фикстуры
android/    Kotlin-приложение (:contract — чистый Kotlin, :data, :ui, :app)
server/     Python-сервер синхронизации
deploy/     скрипт установки и docker-compose
docs/       предложение, ADR
```
